# 单词大王 - 英语单词学习小程序

一款面向幼儿、小学、初中阶段的英语单词学习小程序，提供多种学习模式，帮助用户轻松掌握英语单词。

## 🎯 核心特点

### 阶段差异化设计
- **幼儿园**: 针对学龄前儿童，分类包括礼貌打招呼/教室物品/颜色/数字/身体部位/动物/水果/动作/评价与鼓励等
- **小学**: 适合小学生，分类包括动物世界/食物饮品/学校生活/时间天气/交通工具/家庭生活/情感表达/兴趣爱好等
- **初中**: 适合初中生，分类包括学科词汇/自然环境/日常生活/人际交往/职业工作/健康医疗/科技通讯/社会文化等

### 五种学习模式

1. **图-听-英-汉-拼-句** - 六步法全方位学习，适合各阶段
2. **分类记忆** - 按主题分类学习，各阶段分类完全不同
3. **联想记忆** - 通过形状、读音、动作、颜色、数字等多种联想技巧
4. **故事短文记忆** - 通过故事短文学习单词
5. **词根及相似记忆** - 学习词根词缀和相似词（小学及以上）

## 📚 学习流程

### 选择阶段 → 选择模式 → 学习

每个阶段都有完全适配的分类和内容，不同阶段的相同模式下展现差异化内容。

## 扩展单词库

### 添加单词
在 `data/words.js` 中添加更多单词:

```javascript
{
  id: 'id',
  word: '单词',
  phonetic: '/音标/',
  level: '级别', // kindergarten/primary/junior
  category: '分类', // 对应阶段的分类
  image: 'emoji图标',
  meaning: '中文释义',
  sentence: '英文例句',
  sentenceTranslation: '例句翻译',
  spellTips: '拼写提示',
  similarWords: ['相似词1', '相似词2'],
  root: '词根词缀',
  audio: '发音'
}
```

### 添加联想记忆
在 `data/associations.js` 中添加联想:

```javascript
{
  id: 'assoc_id',
  type: '联想类型', // shape/sound/action等
  word: '单词',
  meaning: '释义',
  image: 'emoji',
  association: '联想方法描述',
  memoryTip: '记忆口诀',
  relatedWords: ['相关词1', '相关词2']
}
```
