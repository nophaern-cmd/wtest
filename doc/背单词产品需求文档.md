# 背单词产品需求文档

## 一、产品概述

### 1.1 产品定位
面向幼儿园、小学、中学阶段的智能背单词应用，通过多种记忆模式和差异化界面设计，帮助学生高效掌握英语词汇。

### 1.2 目标用户
- **幼儿阶段**: 3-6岁幼儿园儿童
- **小学阶段**: 6-12岁小学生
- **中学阶段**: 12-18岁初中和高中生

### 1.3 核心价值
- 针对不同年龄段提供定制化的学习体验
- 多元化记忆模式满足不同学习偏好
- 循序渐进的词汇体系构建
- 趣味性与系统性并重

---

## 二、产品架构

### 2.1 整体流程
```
用户进入 → 选择学习阶段 → 选择学习模式 → 开始学习 → 完成训练 → 查看成果
```

### 2.2 学习阶段
1. 幼儿阶段 (3-6岁)
2. 小学阶段 (6-12岁)
3. 中学阶段 (12-18岁)

### 2.3 学习模式
1. 图-听-英-汉-拼-句 (五步学习法)
2. 分类记忆 (按主题分类)
3. 联想记忆 (词根/音形义联想)
4. 故事短文记忆 (语境学习)

### 3.3 学习界面核心功能

---

#### 3.3.1 模式1: 图-听-英-汉-拼-句

**五步学习流程**

**第一步: 看图感知**
- 展示: 高清插画/照片占据屏幕80%
- 音频: 自动播放单词发音
- 交互: 点击图片再次播放
- 时间: 3秒后自动进入下一步 (可点击跳过)

**第二步: 听音辨义**
- 展示: 图片缩小到左侧 + 音频波形动画
- 操作: "再听一次"按钮
- 交互: 点击播放音频，进度条显示播放进度
- 提示: 引导用户专注听音

**第三步: 英文认知**
- 展示: 英文单词大字显示 (48-72px)
- 音频: 播放单词发音
- 交互: 
  - 点击单词播放发音
  - 显示音标 (中学阶段)
  - 显示词性 (小学/中学阶段)
- 阶段差异:
  - 幼儿: 单词 + 动画
  - 小学: 单词 + 音标
  - 中学: 单词 + 音标 + 词性 + 例句

**第四步: 中文理解**
- 展示: 中文释义
- 交互: 
  - 点击显示更多释义 (多义词)
  - 例句展示 (小学/中学)
- 阶段差异:
  - 幼儿: 一个简单释义
  - 小学: 2-3个释义 + 1个例句
  - 中学: 完整释义 + 2-3个例句

**第五步: 拼写练习**
- 幼儿阶段:
  - 拖拽字母卡片完成拼写
  - 字母顺序提示 (部分显示)
  - 完成后播放欢快音效
  
  小学阶段:
  - 看图填空 (部分字母显示为下划线)
  - 首字母提示
  - 完成后显示完整单词
  
  中学阶段:
  - 完整拼写输入
  - 无提示
  - 实时拼写检查
  - 错误高亮提示

**第六步: 句子应用**
- 展示: 含该单词的句子
- 交互:
  - 句子朗读播放
  - 单词高亮显示
  - 点击单词查看解释
- 阶段差异:
  - 幼儿: 简单3-5词短句 + 朗读
  - 小学: 5-8词句子 + 朗读 + 中文翻译
  - 中学: 完整句子 + 朗读 + 中文翻译 + 语法解析

**学习完成界面**
- 展示: 
  - 正确/错误统计
  - 获得积分/徽章
  - "继续学习" / "查看错词"按钮
- 动画: 撒花/升星动画

**UI 设计要点**
- 进度指示器: 顶部显示当前步骤 (6个圆点)
- 导航: 支持返回上一步
- 自动播放: 默认开启，可关闭
- 音量控制: 右上角音量按钮

#### 3.3.3 模式3: 联想记忆

**联想类型**

**1. 词根词缀联想**
- 前缀联想: 
  - un- (unhappy, unlike, unkind)
  - re- (rewrite, return, replay)
  - pre- (preview, prepare, preheat)
  
- 后缀联想:
  - -er/-or (teacher, doctor, actor)
  - -tion/-sion (action, question, decision)
  - -able/-ible (able, possible, comfortable)

- 词根联想:
  - spect (look, respect, inspect, expect)
  - port (carry, import, export, transport)
  - form (shape, reform, transform, uniform)

**2. 读音相似联想**
- 完全同音:
  - see / sea
  - write / right
  - flower / flour
  
- 部分读音相似:
  - cat / bat / hat / mat
  - light / night / right / fight
  - tree / three / free

**3. 拼写相似联想**
- 仅一个字母不同:
  - cat / bat / hat
  - book / look / cook
  - pen / hen / ten
  
- 拼写规律:
  - tion / sion / cion
  - ough (tough, though, thought, through)

**4. 包含关系联想**
- 一个词包含另一个词:
  - sun / sunny
  - rain / rainy / rainbow
  - care / careful / carefully
  
- 复合词:
  - sun + flower = sunflower
  - book + case = bookcase
  - hand + bag = handbag

**5. 中文含义相似/相反联想**
- 同义词:
  - big / large / huge / enormous
  - happy / glad / joyful / cheerful
  - begin / start / commence
  
- 反义词:
  - big / small
  - happy / sad
  - hot / cold
  - up / down
  - fast / slow

**界面设计**

**联想类型选择页**
- 布局: 5个联想类型卡片
- 卡片设计:
  - 图标 + 类型名称
  - 单词数量
  - 举例说明
  - 适用阶段标记
  
**联想学习页**
**布局**: 左侧联想关系图 + 右侧单词详情

**左侧联想关系图**
- 中心词: 当前学习的单词
- 关连线: 连接到相关单词
- 相关词卡片:
  - 单词
  - 联想类型图标
  - 中文释义
  - 熟练度指示

**右侧单词详情**
- 使用模式1的五步学习法
- 额外展示:
  - 联想关系说明
  - 相关词列表 (可点击切换学习)
  - 联想记忆技巧提示

**阶段差异**
- 幼儿:
  - 主要使用读音相似和拼写相似联想
  - 每组2-3个词
  - 图形化展示 (如 sun ☀️ → sunny ☀️😊)
  - 简化联想说明

- 小学:
  - 全面使用联想类型，逐步引入词根
  - 每组3-5个词
  - 文字+图形结合
  - 详细的联想说明

- 中学:
  - 强调词根词缀系统学习
  - 每组5-8个词
  - 专业化展示
  - 深度解析词源

**特色功能**
1. **联想图谱**: 可视化展示词汇网络
2. **智能推荐**: 基于已学词汇推荐相关联想
3. **关联学习**: 从任一词汇进入，可切换到整个联想组
4. **错词联想**: 自动分析错词，推荐联想记忆法

  - 配语音朗读

  - 寓言故事
  - 科普短文
  - 生活小故事
  - 对话场景
- 篇幅: 50-150词
- 主题:
  - 校园生活
  - 家庭生活
  - 自然科普
  - 文化故事
- 特点:
  - 情节完整
  - 结构清晰
  - 可视化配图
  - 词汇重复率高

**中学阶段**
- 内容类型:
  - 散文随笔
  - 新闻报道
  - 说明文
  - 对话剧本
  - 诗歌片段
- 篇幅: 150-500词
- 主题:
  - 社会热点
  - 文化探讨
  - 科学发现

  - 文学作品
- 特点:
  - 内容深度

**界面设计**

**故事列表页**
- 布局: 卡片式列表
- 每个故事卡片:
  - 封面图/插画
  - 标题

  - 词汇数量

  - 标签 (寓言/科普/文化等)

- 筛选: 
  - 按主题
  - 按难度
  - 按学习状态
- 搜索: 支持标题和内容搜索

**故事学习页**
**布局**: 全屏阅读模式

**阅读区域**
- 文本展示:
  - 幼儿: 大字体 + 拼音 + 插画
  - 小学: 适中字体 + 关键词汇高亮 + 配图

- 生词标注:
  - 下划线标记生词
  - 点击生词显示浮层:
    - 释义
    - 音标 (小学/中学)
    - 例句
    - 加入生词本按钮

- 音频播放:
  - 整篇朗读
  - 逐句朗读 (点击句子)
  - 调节语速
  - 中英切换朗读 (小学/中学)

**功能按钮栏**
- 底部固定:
  - 上一句 / 下一句 (幼儿/小学)
  - 重点词汇模式
  - 难度调整
  - 完成学习

**词汇学习模式**
- 从故事中提取重点词汇
- 使用模式1五步法学习
- 标注词汇在文中的位置
- 返回故事时高亮已学词汇

- 大字朗读模式
- 逐句翻页设计

- 互动元素 (点击图片有音效)
- 自动翻页开关

**小学阶段**
- 标准阅读模式
- 重点词汇高亮
- 词汇表侧边栏
- 阅读进度保存
- 笔记功能 (简单标注)

**中学阶段**
- 专业阅读器
- 生词管理

- 笔记功能 (高亮/批注)
- 分享功能

## 五、交互设计

### 5.1 交互原则
- **幼儿阶段**: 大按钮、简单操作、强反馈、动画丰富
- **小学阶段**: 清晰直观、操作便捷、适度动画
- **中学阶段**: 高效操作、专业感、少而精的动画

### 5.2 动画效果
- 页面切换: 滑动/淡入淡出
- 卡片交互: 缩放、阴影变化
- 按钮点击: 轻微缩小 + 颜色变化
- 加载: 趣味性加载动画 (幼儿) / 简洁加载 (小学/中学)
- 完成任务: 撒花/升星/音效反馈

### 5.3 反馈机制
- **视觉反馈**: 按钮状态变化、进度指示、高亮提示
- **听觉反馈**: 点击音效、正确/错误提示音、完成音效
- **触觉反馈**: 震动反馈 (移动端)
