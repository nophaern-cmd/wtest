# 背单词产品需求文档

## 一、产品概述

### 1.1 产品定位
面向幼儿园、小学、中学阶段的智能背单词应用，通过多种记忆模式和差异化界面设计，帮助学生高效掌握英语词汇。

### 1.2 目标用户
- **幼儿阶段**: 3-6岁幼儿园儿童
- **小学阶段**: 6-12岁小学生
- **中学阶段**: 12-18岁初中和高中生

### 1.3 核心价值
- 针对不同年龄段提供定制化的学习体验
- 多元化记忆模式满足不同学习偏好
- 循序渐进的词汇体系构建
- 趣味性与系统性并重

---

## 二、产品架构

### 2.1 整体流程
```
用户进入 → 选择学习阶段 → 选择学习模式 → 开始学习 → 完成训练 → 查看成果
```

### 2.2 学习阶段
1. 幼儿阶段 (3-6岁)
2. 小学阶段 (6-12岁)
3. 中学阶段 (12-18岁)

### 2.3 学习模式
1. **图-听-英-汉-拼-句** (五步学习法，包含分类记忆)
2. **联想记忆** (词根/音形义联想)
3. **故事短文记忆** (语境学习)

**五步学习流程**

**第一步: 看图感知**
- 展示: 高清插画/照片占据屏幕80%
- 音频: 自动播放单词发音
- 交互: 点击图片再次播放
- 时间: 3秒后自动进入下一步 (可点击跳过)
- 阶段差异:
  - 幼儿: 超大图片，卡通风格，动画效果
  - 小学: 清晰图片，真实照片为主
  - 中学: 专业图片，可点击放大

**第二步: 听音辨义**
- 展示: 图片缩小到左侧 + 音频波形动画
- 操作: "再听一次"按钮
- 交互: 点击播放音频，进度条显示播放进度
- 提示: 引导用户专注听音
- 阶段差异:
  - 幼儿: 波形动画夸张，播放按钮巨大
  - 小学: 标准波形，正常按钮
  - 中学: 精确波形，可选美式/英式发音

**第三步: 英文认知**
- 展示: 英文单词大字显示
- 音频: 播放单词发音
- 交互:
  - 点击单词播放发音
  - 显示音标 (小学/中学)
  - 显示词性 (小学/中学)
- 阶段差异:
  - 幼儿: 单词72px，带动画效果，无音标词性
  - 小学: 单词56px，显示IPA音标，显示词性
  - 中学: 单词48px，显示IPA音标，显示词性，显示同根词

**第四步: 中文理解**
- 展示: 中文释义
- 交互:
  - 点击显示更多释义 (多义词)
  - 例句展示 (小学/中学)
- 阶段差异:
  - 幼儿: 一个简单释义，无例句，大字号32px
  - 小学: 2-3个释义 + 1个简单例句，字号24px
  - 中学: 完整释义 + 2-3个例句 + 词组搭配，字号20px

**第五步: 拼写练习**

**幼儿阶段**
- 拖拽字母卡片完成拼写
- 字母顺序提示 (部分显示，显示50%字母)
- 字母卡片带有动物/物体图标 (A-Apple, B-Bird)
- 完成后播放欢快音效 + 动画奖励
- 错误提示: 字母卡片晃动 + 提示音

**小学阶段**
- 看图填空 (部分字母显示为下划线)
- 首字母提示
- 拼写区域显示剩余字母池
- 实时检查拼写正确性
- 完成后显示完整单词 + 释义

**中学阶段**
- 完整拼写输入 (无提示)
- 实时拼写检查，错误字母高亮
- 支持语音输入
- 完成后显示正确答案 + 同义词/反义词
- 错误3次后显示提示

**第六步: 句子应用**
- 展示: 含该单词的句子
- 交互:
  - 句子朗读播放
  - 单词高亮显示
  - 点击单词查看解释
- 阶段差异:
  - 幼儿: 简单3-5词短句 + 朗读 + 配图
  - 小学: 5-8词句子 + 朗读 + 中文翻译
  - 中学: 完整句子 + 朗读 + 中文翻译 + 语法解析

**学习完成界面**
- 展示:
  - 正确/错误统计
  - 获得积分/徽章
  - "继续学习" / "查看错词"按钮
- 动画: 撒花/升星动画
- 音效: 完成音效

**UI 设计要点**
- 进度指示器: 顶部显示当前步骤 (6个圆点)
- 导航: 支持返回上一步
- 自动播放: 默认开启，可关闭
- 音量控制: 右上角音量按钮
- 分类切换: 右上角返回分类列表

#### 3.3.2 模式2: 联想记忆

**联想类型**

**1. 词根词缀联想**

**前缀联想**
- un- (否定): happy → unhappy, like → unlike, kind → unkind, known → unknown
- re- (重复): write → rewrite, turn → return, play → replay, use → reuse
- pre- (在前): view → preview, heat → preheat, pare → prepare, vent → prevent
- im-/in- (否定/进入): possible → impossible, correct → incorrect, port → import, form → inform
- mis- (错误): understand → misunderstand, lead → mislead, take → mistake
- dis- (分开/否定): appear → disappear, agree → disagree, like → dislike

**后缀联想**
- -er/-or (人/物): teach → teacher, act → actor, sing → singer, visit → visitor
- -tion/-sion (名词): act → action, decide → decision, discuss → discussion
- -able/-ible (可...的): accept → acceptable, possible → possible, comfort → comfortable
- -ful (充满...的): care → careful, hope → hopeful, help → helpful
- -less (无...的): care → careless, hope → hopeless, use → useless
- -ly (副词): quick → quickly, happy → happily, slow → slowly
- -ment (名词): move → movement, develop → development, manage → management

- 背景色: #F5F0FA (浅紫白)
- 特点: 专业稳重，低饱和度

### 4.2 字体规范

**幼儿阶段**
- 英文: Comic Sans MS / 软圆体
- 中文: 幼圆 / 黑体
- 字号: 24-36px (正文)，48-72px (标题)
- 特点: 圆润可爱，易读性强

**小学阶段**
- 英文: Arial / 微软雅黑
- 中文: 微软雅黑
- 字号: 16-20px (正文)，28-36px (标题)
- 特点: 清晰标准，识别度高

**中学阶段**
- 英文: Roboto / 思源黑体
- 中文: 思源黑体
- 字号: 14-16px (正文)，24-28px (标题)
- 特点: 专业简洁，信息密度高

### 4.3 间距规范
- 幼儿: 大间距，按钮高度48-56px，卡片间距20px
- 小学: 适中间距，按钮高度40-48px，卡片间距16px
- 中学: 标准间距，按钮高度36-40px，卡片间距12px

### 4.4 圆角规范
- 幼儿: 16-20px (大圆角)
- 小学: 12-16px
- 中学: 8-12px (标准)

## 五、交互设计

### 5.1 交互原则
- **幼儿阶段**: 大按钮、简单操作、强反馈、动画丰富
- **小学阶段**: 清晰直观、操作便捷、适度动画
- **中学阶段**: 高效操作、专业感、少而精的动画

### 5.2 动画效果
- 页面切换: 滑动/淡入淡出
- 卡片交互: 缩放、阴影变化
- 按钮点击: 轻微缩小 + 颜色变化
- 加载: 趣味性加载动画 (幼儿) / 简洁加载 (小学/中学)
- 完成任务: 撒花/升星/音效反馈

### 5.3 反馈机制
- **视觉反馈**: 按钮状态变化、进度指示、高亮提示
- **听觉反馈**: 点击音效、正确/错误提示音、完成音效
- **触觉反馈**: 震动反馈 (移动端)
