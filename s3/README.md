# 三字经游戏 - 微信小程序

一个寓教于乐的三字经学习微信小程序，通过游戏化的方式帮助用户学习和记忆三字经。

## 功能特点

### 1. 学习模式
- 📚 展示8章经典三字经内容
- 📖 每章附带详细解读
- ⬅️➡️ 方便的章节导航
- 📊 学习进度显示

### 2. 挑战模式
- 🎯 随机生成填空题目
- 💯 每次挑战10道题
- 🔥 连答对有额外加分
- 📈 实时显示得分和连胜
- ✅ 答题后即时反馈
- 🏆 完成后显示详细统计

### 3. 学习统计
- 📊 答题总数统计
- 🎯 正确率计算
- 🔥 最高连胜记录
- ⭐ 最高得分追踪
- 📝 学习建议提示
- 🔄 支持重置数据

## 快速开始

### 前置要求
1. 安装微信开发者工具
2. 注册微信小程序账号

### 使用步骤
1. 克隆或下载项目
2. 打开微信开发者工具
3. 选择"导入项目"
4. 选择项目目录
5. 填写AppID（测试可使用测试号）
6. 点击编译运行

### 添加图标
项目需要在 `images/` 目录下添加以下图标（尺寸建议：81x81px）：
- `learn.png` - 学习图标
- `learn-active.png` - 学习选中图标
- `test.png` - 挑战图标
- `test-active.png` - 挑战选中图标
- `review.png` - 统计图标
- `review-active.png` - 统计选中图标

如果暂时没有图标，可以删除或注释 `app.json` 中的 `tabBar.iconPath` 和 `tabBar.selectedIconPath` 配置。

## 三字经内容

小程序包含8章经典三字经内容：
1. 人之初
2. 养不教
3. 香九龄
4. 三才者
5. 曰水火
6. 曰喜怒
7. 父子恩
8. 小学终

每章包含8句三字经，共计64句，并有详细的解读说明。

- 本地存储学习进度和成绩
- 响应式设计，适配各种屏幕
- 优雅的渐变色和卡片式UI
- 流畅的动画效果

## 数据持久化

使用 `wx.getStorageSync()` 和 `wx.setStorageSync()` 保存以下数据：
- score: 当前得分
- bestStreak: 最高连胜
- totalQuestions: 答题总数
- correctAnswers: 正确答案数

## 开发说明

### 修改题目
编辑 `utils/sanzijing.js` 文件中的 `sanzijingData` 数组可以修改或添加三字经内容。

### 调整题目数量
在 `pages/test/test.js` 中修改 `totalQuestions` 值可以调整每次挑战的题目数量。

### 自定义样式
各个页面的 `.wxss` 文件中可以自定义颜色、间距等样式。
