# 学习大厅小程序

## 📖 项目简介

学习大厅是一个综合性的微信小程序，整合了**英语学习**和**国学学习**两大模块，为用户提供丰富的学习内容和良好的学习体验。

## ✨ 功能特性

### 🏠 学习大厅（首页）
- 统一的学习入口
- 今日推荐（每日一句）
- 学习统计展示
- 快速导航到各学习模块

### 📚 英语学习（完整复制自 kd 项目）
- **首页**：学习概览
- **词汇学习**：基础词汇、自然拼读
- **句型学习**：常用句型练习
- **儿歌学习**：经典英语儿歌
- **故事阅读**：英语绘本故事
- **测试功能**：学习效果检测

### 📖 国学学习（基于 s3 项目）
- **三字经**：经典国学启蒙
- **古诗词**：精选古诗词学习
- **详细注释**：逐句注释和解读
- **语音朗读**：支持课文朗读

## 🚀 快速开始

### 1. 安装微信开发者工具
前往 [微信开发者工具官网](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html) 下载并安装。

### 2. 导入项目
1. 打开微信开发者工具
2. 选择"导入项目"
3. 选择项目目录：`/Users/dulin03/work/wtest/s3`
4. 填写 AppID（可在微信公众平台注册获取，测试可选"测试号"）

### 3. 运行项目
点击开发者工具中的"编译"按钮即可运行。

## 🎯 使用说明

### 英语学习
1. 点击首页"英语学习"模块
2. 选择学习内容：词汇、句型、儿歌、故事等
3. 点击喇叭图标播放发音
4. 完成测试检验学习效果

### 国学学习
1. 点击首页"国学学习"模块
2. 选择分类：三字经或古诗词
3. 点击课程查看详细内容
4. 点击"显示注释"查看解读
5. 点击"播放"听取朗读

## ⚙️ 配置说明

### 微信同声传译插件
项目已配置微信同声传译插件，用于语音朗读功能。

插件配置（已在 `app.json` 中添加）：
```json
{
  "plugins": {
    "WechatSI": {
      "version": "0.3.3",
      "provider": "wx069ba97219f66d99"
    }
  }
}
```

如需使用语音功能，请在微信公众平台添加插件：
1. 登录微信公众平台
2. 进入"设置" -> "第三方设置" -> "插件管理"
3. 搜索"微信同声传译"
4. 添加并授权

## 📊 数据扩展

### 添加英语内容
在 `app.js` 的 `globalData` 中添加：
- `words.basic`：基础词汇
- `words.phonics`：自然拼读词汇
- `sentences`：常用句型
- `songs`：英语儿歌
- `stories`：绘本故事

### 添加国学内容
在 `app.js` 的 `globalData.guoxue` 中添加：
- `sanzijing`：三字经内容
- `poems`：古诗词内容
