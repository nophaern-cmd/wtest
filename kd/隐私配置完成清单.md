## 📋 微信后台配置清单

### 第一步: 登录微信公众平台
- 访问: https://mp.weixin.qq.com
- 使用小程序管理员账号登录

### 第二步: 进入隐私保护指引配置
**方式1:**
1. 点击左侧菜单 **"设置"**
2. 找到 **"服务内容声明"** 模块
3. 点击 **"用户隐私保护指引"**

**方式2:**
1. 进入 **"版本管理"**
2. 点击 **"提交审核"**
3. 在审核表单中填写隐私保护指引

### 第三步: 填写隐私保护指引内容

#### 3.1 基本信息
```
小程序名称: 快乐英语学习
开发者主体: (填写你的主体信息)
联系方式: (填写你的联系方式)
```

#### 3.2 隐私政策文本
```
欢迎使用"快乐英语学习"小程序。我们非常重视您的个人信息保护。

一、我们收集的信息
1. 学习进度数据: 包括您已学习的词汇数量、句型数量、测试成绩记录

三、信息保护

2. 您可以随时清除小程序数据删除所有信息

四、您的权利
1. 查看学习进度和统计数据

3. 卸载小程序即可删除所有存储信息

五、未成年人保护
本小程序主要面向儿童用户,我们特别重视未成年人隐私保护。
所有数据仅存储在家长控制的设备上,家长可以随时查看和清除孩子的学习数据。

六、联系我们
小程序名称: 快乐英语学习
AppID: wxe936752af84be780
```

### 第四步: 选择收集的个人信息类型

#### 必须勾选
- [x] **用户生成的数据**: 学习进度、测试成绩等
- [x] **设备信息**: 设备基础信息(用于音频播放)

#### 不收集(不勾选)
- [ ] 用户身份信息(姓名、手机号等)
- [ ] 位置信息
- [ ] 相册、相机权限
- [ ] 联系人信息

### 第五步: 选择使用的接口权限

#### 必须勾选
- [x] **本地存储接口**: wx.getStorageSync, wx.setStorageSync
- [x] **震动接口**: wx.vibrateShort
- [x] **页面跳转接口**: wx.navigateTo, wx.switchTab, wx.reLaunch
- [x] **音频播放接口**: wx.createInnerAudioContext

#### 可选勾选
- [ ] 语音合成接口(TTS): wx.createTtsContext
