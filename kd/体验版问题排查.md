# 体验版无法显示问题排查指南

## 已修复的问题

### 1. privacyAgree 设置
**问题**: `project.config.json` 中 `privacyAgree: false` 可能导致体验版无法正常加载

**修复**:
```json
"privacy": {
  "open": true,
  "ver": 1,
  "privacyAgree": true  // 改为 true
}
```

### 2. permission 配置
**问题**: app.json 中不必要的 permission 配置可能导致体验版启动失败

**修复**:
```json
"permission": {}  // 清空不需要的权限
```

### 3. 隐私弹窗延迟加载
**问题**: 隐私弹窗在组件 attached 时立即检查,可能影响页面初始化

**修复**:
```javascript
lifetimes: {
  attached() {
    // 延迟检查,避免影响页面初始化
    setTimeout(() => {
      this.checkAgreement()
    }, 500)
  }
}
```

## 体验版无法显示的其他可能原因

### 1. 基础库版本问题
**检查步骤**:
1. 打开微信开发者工具
2. 点击右侧详情
3. 查看"本地设置" → "调试基础库版本"
4. 建议使用 2.19.4 或更高版本

### 2. 页面路径问题
**检查步骤**:
1. 确认 app.json 中第一个页面是首页
2. 确认首页文件存在且无语法错误

**当前配置**:
```json
"pages": [
  "pages/privacy/privacy",  // 不应该作为首页!
  "pages/index/index",     // 应该是首页
  ...
]
```

**需要修复**: 将隐私页面移到第二位

### 3. 组件注册问题
**检查步骤**:
1. 确认 components/privacy-popup 目录存在
2. 确认组件文件完整(.js, .json, .wxml, .wxss)
3. 确认 app.json 中的组件路径正确

### 4. 编译错误
**检查步骤**:
1. 打开微信开发者工具
2. 查看控制台是否有报错
3. 查看编译器输出是否有错误

## 立即执行的操作

### 操作1: 修复页面顺序(最重要!)
将 `pages/privacy/privacy` 从第一位移到最后一位:

```json
{
  "pages": [
    "pages/index/index",      // 首页
    "pages/words/words",
    "pages/sentences/sentences",
    "pages/phonics/phonics",
    "pages/songs/songs",
    "pages/stories/stories",
    "pages/quiz/quiz",
    "pages/test/test",
    "pages/privacy/privacy"   // 移到最后
  ]
}
```

### 操作2: 清除缓存并重新编译
1. 在微信开发者工具中
2. 点击"工具" → "清除缓存" → "全部清除"
3. 重新编译(Ctrl+B 或 Cmd+B)

### 操作3: 检查控制台错误
1. 查看开发者工具控制台
2. 记录所有错误信息
3. 逐个解决错误

## 常见错误及解决方案

### 错误1: 页面不存在
```
Error: Page is not found: pages/privacy/privacy
```
**解决**: 确认隐私页面文件存在

### 错误2: 组件未注册
```
Error: Component is not found in path "components/privacy-popup/privacy-popup"
```
**解决**: 确认组件文件完整

### 错误3: 语法错误
```
Error: Unexpected token in JSON
```
**解决**: 检查 JSON 文件语法,使用在线 JSON 验证工具

### 错误4: 体验版权限不足
```
Error: Permission denied
```
**解决**:
1. 确认小程序已审核通过
2. 确认体验版权限已开启
3. 重新上传体验版

## 上传体验版的正确步骤

### 1. 准备工作
- [ ] 确认代码无错误
- [ ] 确认所有页面文件完整
- [ ] 确认组件文件完整
- [ ] 确认配置文件正确

### 2. 修改配置
- [ ] 将首页设置为 pages/index/index
- [ ] 移除不必要的 permission 配置
- [ ] 确认 privacy 配置正确

### 3. 编译测试
- [ ] 在开发者工具中编译
- [ ] 测试所有页面功能
- [ ] 检查控制台无错误

### 4. 上传体验版
1. 点击开发者工具"上传"按钮
2. 填写版本号(如: 1.0.0)
3. 填写项目备注

5. 等待上传完成

1. 登录微信公众平台
2. 进入"版本管理"
3. 找到刚上传的版本
4. 点击"设为体验版"
5. 添加体验成员
