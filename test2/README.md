# 趣味学习刷题小程序

一款面向中小学生的游戏化学习刷题微信小程序，通过多种有趣的游戏模式让学习变得有趣。

## 项目特点

- 🎮 **多种游戏模式**：知识扑克、答题大作战、知识坦克
- 📚 **多学科支持**：语文、数学、英语、历史
- 🎯 **难度分级**：小学、中学两个难度等级
- 📊 **学习统计**：详细的学习数据和成就系统
- 💾 **本地存储**：自动保存学习进度

## 游戏模式介绍

### 1. 知识扑克 🃏
- 翻开两张卡片，判断是否是正确的知识点配对
- 连续答对获得连击加分
- 适合记忆性知识点学习

### 2. 答题大作战 🐦
- 选择正确答案发射小鸟击碎障碍
- 错误答案会反弹扣分
- 连续命中获得连击奖励

### 3. 知识坦克 🎮
- 守护知识堡垒，防御敌军进攻
- 选择正确答案攻击敌人
- 敌人接近堡垒会扣血

## 学科内容

### 语文 📖
- **小学**：基础汉字、简单古诗、成语故事
- **中学**：进阶诗词、文言文、成语典故

### 数学 🔢
- **小学**：基础计算、简单几何、数学概念
- **中学**：代数、几何、方程、概率

### 英语 🅰️
- **小学**：基础词汇、简单语法
- **中学**：进阶词汇、语法结构、阅读理解

### 历史 📜
- **小学**：古代四大发明、长城等基础历史
- **中学**：丝绸之路、三国历史、朝代更替

## 使用说明

1. 在微信开发者工具中打开项目
2. 选择学科和难度
3. 选择游戏模式开始学习
4. 查看统计页面了解学习进度

## 技术特点

- 纯微信小程序原生开发
- 本地存储学习数据
- 响应式设计
- 流畅的动画效果
- 模块化代码结构

## 数据统计功能

- 总得分和游戏次数
- 各学科进度和正确率
- 各游戏模式统计
- 学习记录和成就徽章
- 支持数据清除重置

## 扩展题库

在 `app.js` 的 `getChineseQuestions()`, `getMathQuestions()`, `getEnglishQuestions()`, `getHistoryQuestions()` 方法中可以轻松扩展更多题目。

## 注意事项

- 题库目前为示例数据，实际使用需要添加更多题目
- 建议根据实际学习需求调整游戏规则和计分方式
- 可以根据学生年级进一步细分难度等级
